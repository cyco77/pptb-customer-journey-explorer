# Security Policy

## Reporting a Vulnerability

Please do **not** open a public issue.
Use GitHub Security Advisories: [https://github.com/cyco77/pptb-customer-journey-explorer/security/advisories/new](https://github.com/cyco77/pptb-customer-journey-explorer/security/advisories/new)

## Scope

- Authentication flows
- Token handling
- Dataverse request logging
- Dependency vulnerabilities
